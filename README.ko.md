# PickNote

한국어 · **[English](README.md)**

리그 오브 레전드 **KR 솔로랭크 저티어 (아이언~플래티넘)**용 밴픽 도우미이자, 개인 통계를 바탕으로 피드백을 제공하는 롤 어시스턴트입니다. 개인 PC에서 사용할 목적으로 개발되었습니다. 타인의 PC 및 공용 PC에서 돌릴 시 API, 계정 등이 유출 될 수 있음으로 주의 부탁드립니다. 

챔피언 선택 중에 클라이언트에서 밴픽 상황을 읽어, 내 포지션에서 어떤 챔피언이 우리 팀 승률을 가장 높이는지와
**그 이유**(챔피언 자체 강함 · 아군과의 궁합 · 상대와의 상성)를 보여 줍니다.

- 각 패치에 최적화 된 티어표가 아닌 **실제 KR 랭크 약 170만 경기**(아이언~플래티넘, 16.15~16.21 패치)로 학습했습니다. 즉, 진짜 챔피언 간의 매커니즘 상성을 학습하였습니다.
- **팀원 전원 혹은 적팀 전원이 나온 상태에서만 추천하지 않습니다.** 지금까지 나온 챔피언들과의 시너지를 바탕으로 최선의 픽을 알려줍니다.
- 클라이언트는 **읽기만** 한다. 대신 픽·밴을 누르지 않습니다. 스펠과 룬을 조작하지 않기에 직접 선택하셔야 합니다. 
- 한국어 / English 선택 가능합니다.
- 기본은 한국 서버입니다. 다른 서버에서 플레이하신다면 설치할 때 서버를 고르실 수 있습니다.

## 빠른 시작 (윈도우)

1. [Releases](https://github.com/taejogmin/PickNote/releases)에서 최신 **Source code (zip)** 을 받아 **압축을 풉니다** (오른쪽 클릭 → 압축 풀기).
2. **`0_Setup.cmd`** 를 더블클릭합니다. 파이썬과 필요한 것을 이 폴더 안에 알아서 설치하므로 파이썬을 따로 설치하실 필요가 없습니다. 언어와 서버를 고르시면 됩니다 (엔터만 누르면 한국).
3. **`3_Open.cmd`** 를 더블클릭하면 브라우저에 화면이 뜹니다. 게임에서 챔피언 선택에 들어가면 밴픽이 저절로 채워집니다.

추천만 필요하다면 여기까지만 진행하셔도 됩니다. 하지만 최신 패치 데이터와 개인 통계가 기능을 사용하고 싶으시면 아래를 참조하세요. 

| 파일 | 하는 일 |
|---|---|
| `0_Setup.cmd` | 처음 한 번. 파이썬·패키지 설치, 언어, 서버 |
| `1_ApiKey.cmd` | Riot 개발자 사이트와 메모장을 열어 API 키를 넣게 합니다 (24시간 마다 API갱신 필요합니다)|
| `2_Collect.cmd` | 고른 서버의 새 경기를 모읍니다 (API 키 필요). 켜 두시면 됩니다 |
| `3_Open.cmd` | 화면을 엽니다 |
| `4_MyRecord.cmd` | 메모장에 내 Riot ID를 적게 하고, **내 기록** 화면에 쓸 내 경기를 받습니다 |
| `Update.cmd` | 새 버전 (묻고 설치) · 새 경기로 다시 학습 · 내 기록 갱신 |
| `Settings.cmd` | 언어 · 서버 바꾸기 |
| `Status.cmd` | 얼마나 모였는지, 키가 아직 통하는지 |
| `advanced\` | 고티어 수집, 로그인할 때 수집기 자동 시작, 강제 재학습, 승패 육각형 기준 받기 |

### API 키 (수집과 *내 기록*에 필요)

경기를 모으거나 내 기록을 받으려면 무료 **Riot 개발용 API 키**가 필요합니다.
`1_ApiKey.cmd` 를 실행해 developer.riotgames.com 에 로그인하고 *Regenerate API Key* 를 누른 뒤, `RGAPI-…` 키를 열린 메모장에 붙여 넣고 저장하시면 됩니다.
개발용 키는 24시간마다 만료됩니다. 수집기는 키가 만료돼도 멈추지 않고, 새 키를 넣으면 이어서 받습니다.

### 내 기록과 서버

`4_MyRecord.cmd` 를 실행하면 메모장이 열립니다. 내 Riot ID(`이름#태그`)를 한 줄에 하나씩 적고 저장하시면 됩니다.
설정한 서버와 다른 서버의 계정은 뒤에 `@서버`를 붙여 주세요. 예: `Name#EUW @euw1`

서버 코드: `kr` `jp1` `na1` `br1` `la1` `la2` `euw1` `eun1` `tr1` `ru` `me1` `oc1` `sg2` `tw2` `vn2`

### 최신으로 유지하기

가끔 `Update.cmd` 를 실행해 주세요.

1. 새 버전이 있으면 **물어보고 설치**합니다 (키 · 계정 · 수집 데이터 · 모델은 그대로 둡니다)
2. 직접 모은 경기가 충분히 쌓였으면 **다시 학습**합니다 — 새 모델이 지금 모델보다 못하면 지금 모델을 그대로 씁니다
3. `my_accounts.txt` 에 적은 계정의 새 경기를 받습니다

**다시 학습은 언제?** 수집한 경기는 공개하지 않으므로(아래 *데이터와 개인정보*), 처음에는 들어 있는 모델을 씁니다.
직접 모은 경기가 **30만 판**을 넘으면 그 경기로 처음 학습하고, 그 뒤로는 새 경기 3만 판(새 패치면 1만 판)마다 다시 학습합니다.
개발용 키로 하루 약 5만 판이 모입니다.

**필요한 사양:** 다시 학습하려면 **메모리 8GB 이상**을 권장합니다 (16GB면 여유). 약 200만 판 기준으로 16~17분, 메모리는 최대 약 5.2GB를 썼습니다. 추천만 쓰실 때는 거의 들지 않습니다.

**다른 서버:** 들어 있는 모델은 한국 데이터로 학습했습니다. 다른 서버를 고르시면 그 서버 경기를 30만 판 모을 때까지 한국 모델을 쓰고, 화면 위에 그렇게 표시됩니다.

## 데이터와 개인정보

- **수집한 경기 데이터는 공개하지 않습니다.** Riot API 약관상 받은 게임 정보를 다른 사람에게 넘길 수 없기 때문입니다. 공개하는 것은 그 경기들로 학습한 모델(집계된 값)뿐이고, 경기는 각자 자기 키로 모읍니다.
- 모은 경기는 내 PC의 `data/` 에만 있습니다.
- *내 기록*은 내 PC의 `data/me.db` 에만 있습니다. 다른 플레이어의 이름·ID는 저장 전에 지우고, 같은 팀은 "같은 사람과 또 한 판"만 알 수 있게 소금 친 해시로만 남깁니다.
- API 키는 내 PC의 `.env` 에만 있고 Riot에만 보냅니다.
